      About

      Project

      This dashboard is Phase 01 of the “Pakistan Air Quality and Weather” project: an ETL pipeline (pandas + Pydantic validation, loaded into a SQLite database) followed by a structured exploratory data analysis.

      Data

      Hourly observations of pollutants (PM2.5, PM10, CO, NO₂, SO₂, O₃, dust) and weather (temperature, humidity, precipitation, wind speed/direction, pressure) for the cities listed in the filter. The data is downloaded live from the free Open-Meteo API and refreshed automatically every hour, so the numbers and charts keep changing. Every number on this site is computed from the processed dataset.

      Derived AQI

      The source file contains an AQI category but no numeric AQI. A numeric AQI is derived from PM2.5 with the US EPA breakpoints (and verified against the supplied category). It reflects PM2.5 only.

      Scope

      Machine learning, prediction and forecasting are not part of Phase 01; they belong to later phases.

      Stack

      Python · pandas · Pydantic · SQLite · Flask · Open-Meteo API · HTML/CSS/JavaScript · Chart.js
